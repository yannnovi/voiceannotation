voiceannotate est installé. Ouvrez-le depuis le dossier Applications, ou avec Spotlight.

À la première ouverture, macOS peut indiquer que l'application provient d'un développeur non identifié. C'est parce qu'elle n'est pas signée avec un certificat de développeur Apple, pas parce qu'elle a un problème. Pour l'ouvrir malgré tout : clic droit sur l'application, puis Ouvrir ; ou Réglages Système › Confidentialité et sécurité, puis Ouvrir quand même. Ce n'est demandé qu'une fois.

Les transcriptions sont enregistrées à côté du fichier audio, sous le même nom avec l'extension .txt. Les modèles téléchargés depuis l'application vont dans ~/.voiceannotate/models.

Une version en ligne de commande se trouve dans l'application :
/Applications/voiceannotate.app/Contents/MacOS/voiceannotate-cli --help
