About voiceannotate

Transcription with speaker annotation, in a browser.

Engine: Vosk (Kaldi), running on the server, entirely offline. This page drives the same voiceannotate engine as the desktop application.

Voices are grouped from the speaker embeddings the speaker model produces. The sensitivity slider redoes that grouping without reprocessing the audio.
